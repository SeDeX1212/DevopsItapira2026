# Visualizador BFS x DFS

Projeto desenvolvido em Python e Pygame para demonstrar visualmente:

- Breadth First Search (BFS)
- Depth First Search (DFS)

## Funcionalidades

- Geração aleatória de labirintos
- Visualização passo a passo
- Exibição da fronteira de busca
- Reconstrução do caminho encontrado
- Comparação entre BFS e DFS

## Tecnologias

- Python 3.12
- Pygame
- GitHub Actions
- PyInstaller

## Controles

B - Executar BFS
D - Executar DFS
R - Gerar novo labirinto
